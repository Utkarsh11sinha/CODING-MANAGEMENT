# Agent Control Requirement

The agent must never run a force push (`--force`, `--force-with-lease`, `-f`, or a `+refspec` such as `+main`), a mirror push (`--mirror`), or a remote branch deletion (`--delete`, `-d`, or a `:refspec` such as `:main`) in this repository. The only exception is an authorized maintenance window in which a senior developer has explicitly given a temporary override instruction. `CLAUDE.md` points here before any `git push`, so any task that involves pushing should trigger this document; a task with no push, such as fixing checkout code or running the tests, should not.

The `PreToolUse` hook in `.claude/settings.json` runs `.claude/hooks/agent-control.sh` on every Bash tool call and blocks any command in which `push` is followed by one of those forms in the same command segment; normal pushes such as `git push origin main` are allowed. An instruction alone is not enough, because an agent can ignore or misread it; the hook blocks matching commands whatever the agent intends. It is a backstop, not a guarantee: it checks only Bash tool calls and misses some forms, so the rule applies in every case. Its tests and known limitations are in `docs/agent-control-evidence.md`.
